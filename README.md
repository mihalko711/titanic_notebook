# Чему посвящен это проект?

В этом проекте рассматривается [датасет][https://www.kaggle.com/competitions/titanic/data] с Kaggle про пассажиров титаникиа.

Целью моделей является классификация выжил/не выжил на пассажирах.

В пока что единственном ноутбуке `titanic_intro.ipynb` организован небольшой просмотр данных и сравнение базовых моделей:

- логистическая регрессия
- метод опорных векторов
- случайный лес
- градиентный бустинг на деревьях(sklearn, XGBoost, catboost)


Для каждого из методов проведен подбор оптимальных гиперпараметров через случайный поиск, возможно стоит добавить глобальное сравнение лучших моделей и попробовать блендинг или стекинг, но пока что просто так.

Также для лучших моделей в каждом из классов построены калибровочная кривая, ROC - кривая, PrecisionRecall - кривая и матрица ошибок.
